## 📋 核心知识点总结

### 1. 系统架构
- **前端**: Vue 3.5 + TypeScript + Vite 8 + Element Plus + Pinia
- **后端**: Spring Boot 2.7.18 + MyBatis-Plus + Spring Security
- **数据库**: MySQL 8.0 (utf8mb4) + Redis 7
- **通信**: RESTful API + SSE 流式推送

### 2. 功能模块（10大模块）
1. **Agent 管理** - 创建、配置（模型/Prompt/工具绑定/记忆/执行）
2. **工具市场** - API 工具注册、连通性测试、调用统计（MCP 未实现）
3. **编排引擎** - 可视化工作流、执行引擎（条件分支 + 人工审批暂停/恢复）
4. **知识库** - 文档直传（≤50MB）、解析分块、向量化、RAG 检索
5. **会话控制台** - 实时对话、SSE 真流式、执行步骤可视化
6. **监控中心** - 真实指标、告警规则定时评估、告警记录
7. **成本管理** - Token 统计、预算真扣减、超支熔断
8. **安全审计** - RBAC 角色、审批中心、审计日志（账户隔离：仅本人记录）、活动流
9. **工作空间** - 成员管理、空间设置（Agent 执行环境策略：沙箱/共享目录/工具禁用/沙箱外总闸）、空间动态
10. **认证授权** - JWT Token、登录注册

### 3. 技术亮点
- **Vue Flow** - 可视化工作流编排画布
- **SSE** - Agent 对话真流式（thinking/content/done/error 事件，线程池化）
- **工作流引擎** - 沿边遍历执行、条件路由、审批暂停恢复、逐节点结果落库
- **RAG** - 文档解析（PDF/docx）、分块向量化、检索增强生成
- **RBAC** - 角色权限访问控制
- **审计日志** - 全链路操作追溯（审计日志 + 空间活动流双写）

### 4. 数据库设计
- 共 **30+ 张数据表**
- 以工作空间(workspace)为隔离单元
- JSON 字段存储复杂配置（如 Agent 的 model_config）
- 统一字段: created_at, updated_at, created_by, workspace_id
